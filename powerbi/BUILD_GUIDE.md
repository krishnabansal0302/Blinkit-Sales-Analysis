# Power BI dashboard build guide

The project includes an interactive browser dashboard at `dashboard/index.html` and a Power BI-ready cleaned CSV. A native `.pbix` must be saved from Power BI Desktop; it cannot be generated by this Python project. Follow these steps to create the native Power BI file.

## 1. Load the data
1. Open Power BI Desktop.
2. Select **Get data → Text/CSV**.
3. Choose `data/processed/blinkit_cleaned.csv`.
4. Select **Transform Data** and confirm numeric types:
   - `Outlet Establishment Year`: Whole number
   - `Item Visibility`, `Item Weight`, `Sales`, `Rating`: Decimal number
   - remaining columns: Text
5. Select **Close & Apply**.
6. In Model view, rename the table to `blinkit_cleaned`.
7. In Report view, use **Modeling → New measure** and paste measures from `DAX_measures.txt` one at a time.

## 2. Recommended one-page layout

Canvas: 16:9, page background #F5F7F6. Use a dark green header (#092D20), green accent (#0C8B53), and light lime accent (#C7EF4B).

Top row — five Card visuals:
- `[Total Sales]`
- `[Average Sales per Record]`
- `[Average Rating]`
- `[Unique Products]`
- `[Unique Outlets]`

Middle row:
- Clustered bar: Axis `Item Type`, Values `[Total Sales]`; sort descending.
- Clustered bar: Axis `Outlet Type`, Values `[Total Sales]`.
- Column chart: Axis `Outlet Location Type`, Values `[Total Sales]`.

Bottom row:
- Donut: Legend `Item Fat Content`, Values `[Total Sales]`.
- Column chart: Axis `Outlet Establishment Year`, Values `[Total Sales]`. Title it **Sales by Outlet Establishment Year** — this is a comparison by outlet cohort, not transaction-time trend.
- Slicers: `Outlet Type`, `Outlet Size`, `Outlet Location Type`, `Item Type`, `Item Fat Content`.

Format sales measures as currency/number with thousands separators. Average Rating to 2 decimals. Enable data labels where legible. Add a small note: “Average sales per dataset record is not average order value. Dataset has no order ID, transaction date, cost or profit.”

## 3. Save
Save the report as `powerbi/Blinkit_Sales_Analysis.pbix`.

## 4. Validate
- Clear all slicers: Total Sales should be approximately 1,201,681.49.
- Record Count should be 8,523.
- Unique Products should be 1,559.
- Unique Outlets should be 10.
- Average Rating should be approximately 3.97.
